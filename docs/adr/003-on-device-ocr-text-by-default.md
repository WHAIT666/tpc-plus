# ADR-003: On-device OCR, text by default

**Status:** Accepted · 2026-11-20

## Context

Homework photos can show the child's name, handwriting and school. Sending images costs more and is slower.

## Decision

Scanning and OCR run on the tablet (ML Kit). By default only the **extracted text** and quality metrics are sent. An image is sent only as an exception the parents have authorised, and images are never stored.

## Alternatives considered

- **Always send the photo to a vision model** — simpler, better on maps and tables, but worse for privacy, cost and latency.

## Consequences

OCR may lose fractions, maps and tables. This is mitigated by the OCR quality gate, manual topic choice and the authorised-image fallback. Maths only needs OCR to identify the topic, because exercises are generated by code.
