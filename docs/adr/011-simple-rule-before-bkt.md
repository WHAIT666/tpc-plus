# ADR-011: Simple rule before BKT

**Status:** Accepted · 2026-11-20

## Context

Bayesian Knowledge Tracing needs data to fit, and data we don't have yet.

## Decision

Start with a simple, explainable rule for level and mastery, plus a placement check (6–8 mixed-level questions), spaced review (2, 7, 21 days) and fixed fortnightly check-ins. BKT enters in M7, only if it predicts better offline than the rule.

## Alternatives considered

- **BKT from day one** — unfitted parameters and harder to explain.

## Consequences

Progress is reported from the fixed check-ins as *evidence of progress, not proof of cause*.
